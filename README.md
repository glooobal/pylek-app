<h1 align="center">Pyłek!</h1>

<p align="center">
  A mobile app for allergy sufferers – check pollen levels in your area.
</p>

<div align="center">
  Pyłek (Polish for *pollen*) helps people with pollen allergies stay on top of pollen levels. It uses the Google Pollen API to show data for your location and sends push notifications so you're always up to date. Available for iOS and Android.
